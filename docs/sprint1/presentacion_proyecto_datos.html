Contexto de negocio

Los datos ya existen. El valor todavía no se ha extraído.

Una plataforma de e-commerce genera dos flujos muy distintos: la historia transaccional del negocio y el pulso en tiempo real de sus usuarios. Hoy, solo el primero se aprovecha.

AS-IS · Diagnóstico actual

Los datos transaccionales (clientes, productos, pagos, pedidos, inventario) viven en una base de datos operacional. Los eventos de comportamiento — búsquedas, clics, carritos — se generan constantemente pero no se procesan de forma sistemática. El resultado: ventas perdidas, decisiones de inventario menos precisas y marketing menos efectivo.

TO-BE · Visión de la solución

Un pipeline con dos flujos diferenciados — batch para lo transaccional, streaming para los eventos — que consolida ambos mundos en una capa analítica única, disponible para BI y para un motor de recomendación basado en el comportamiento reciente del usuario.

Formulación del problema

Un objetivo, tres disciplinas ejecutándolo en paralelo

Diseñar, implementar y desplegar una arquitectura multicloud y Lakehouse — AWS, GCP y Azure/Power BI — que alimente un motor de recomendaciones y un tablero analítico de negocio.

Sistemas Intensivos en Datos

Pipeline híbrido: eventos en tiempo real vía GCP Pub/Sub y datos transaccionales batch vía JDBC hacia AWS Glue (PySpark), desacoplando el camino rápido a DynamoDB del Lakehouse Iceberg en S3.

Bases de Datos Avanzadas

Modelo clave-valor en DynamoDB para perfiles en milisegundos, particionamiento de tablas Iceberg, y análisis de compresión, indexación y compromisos del Teorema CAP.

Gestión y Gobernanza

Marco DAMA-DMBOK: catálogo y linaje de datos de punta a punta, pruebas de calidad entre capas y enmascaramiento/hashing de PII.

Alcance y restricciones

Lo que se construye — y lo que deliberadamente se deja fuera

Incluye

  • Arquitectura multicloud: GCP (Pub/Sub), AWS (Glue, S3+Iceberg, DynamoDB, Athena), Azure/Power BI.
  • Ingesta desde streaming web y batch JDBC transaccional.
  • Arquitectura Medallón: Bronze crudo, Silver limpio, Gold agregado.
  • Catálogo de datos, linaje end-to-end y políticas de anonimización PII.
  • Dashboard interactivo en Power BI conectado al motor analítico.

No incluye

  • Entrenamiento de modelos de ML/Deep Learning — recomendación por reglas y SQL.
  • Frontend/backend real del e-commerce — se simulan eventos y datos de muestra.
  • Despliegue de asistentes o agentes de IA generativa.
  • Clusters permanentes: solo servicios serverless por presupuesto educativo.
  • Cumplimiento: Ley 1581 de 2012 (Habeas Data), hashing SHA-256 de PII.
